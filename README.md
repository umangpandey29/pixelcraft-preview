# PixelCraft Studio — v5 "VIVID"

Creative agency sample site for Code Liberate, designed from the 9 award
references Umang provided (Kindos, Velto, Belzino, Gromuse, Premium Garments,
Roplant, Homeis, Spesial Sounds, Dew) — 2026-10-21.

Patterns taken from the references:
- Massive uppercase hero with gradient-highlight word + serif italic mix
  (Velto / Roplant / Spesial Sounds), word-by-word masked reveal
- Oversized outlined background numerals & marks (Spesial Sounds "2008")
- Tilted amber marquee band (Roplant yellow CTA energy)
- Floating glass stat panel with count-ups + stars (Premium Garments /
  Kindos)
- Numbered sections with eyebrow labels (Velto "02 / PERFORMANCE")
- Horizontal snap-scroll case rail with conic border-beam hover (21st.dev)
- Bento glass services grid with SVG icons (Dew glassmorphism)
- Count-up stats strip (Velto spec sheet)
- Impact progress bars (Kindos donation progress)
- Magnetic CTAs, aurora blobs, custom cursor, grain

QA: Playwright 50/50, zero JS errors, zero overflow desktop + 390px,
reduced-motion fully respected. Lighthouse Perf 89-95 / A11y 98 / BP 100 /
SEO 100 per page.
